# Development Basics: Python

## Prerequisites

* Python 3
* Git
* PyCharm


## Setup / Installation 

### 1. Clone the repo

```bash
git clone https://github.com/Nkosikk/ndosiautomationdevbasics.git
cd ndosiautomationdevbasics
```

### 2. Open folder on PyCharm

1. Import the project
    * Open PyCharm 
    * Select File -> Open, and choose the clone project folder
